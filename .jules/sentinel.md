## 2026-08-11 - DOM-based XSS and Infinite onerror Loop Hardening
**Vulnerability:** DOM-based Cross-Site Scripting (XSS) via dynamic template string interpolation in grid.innerHTML, and infinite loading/rendering loop Denial of Service (DoS) inside image onerror handlers when local fallback assets are missing.
**Learning:** Concatenating variables directly into innerHTML is unsafe even in static web applications if the source values are external or dynamic. Programmatic DOM construction via document.createElement is the preferred secure alternative. Furthermore, if the fallback image used in an onerror handler itself fails to load or encounters network/protocol restrictions, it causes an infinite loading loop. This must be prevented by setting 'this.onerror = null' prior to updating the image source.
**Prevention:** Always use safe DOM APIs (like document.createElement) instead of parsing dynamic strings into innerHTML, assign onerror fallback handlers before assigning src to avoid race conditions, and always reset the handler with 'this.onerror = null' inside fallback code blocks.
